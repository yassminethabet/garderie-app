# garderie-app

Application web de présentation d'une garderie d'enfants.

## Technologies

- Next.js
- React
- Bootstrap 5
- Node.js
- Express
- Git et GitHub

## Installation

```bash
npm install
```

## Lancement

```bash
npm run dev
```

Ouvrir http://localhost:3000 dans le navigateur.

## Fonctionnalités

- Navbar
- Page d'accueil
- Présentation des services
- API REST pour les services et activités

## Auteur

Projet réalisé dans le cadre d'un TP de développement Web.
